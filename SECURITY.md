# Security policy

Please report security vulnerabilities privately, never in a public issue or pull request.

All Euro-Office repositories share one place for reports:
[Report a vulnerability](https://github.com/Euro-Office/security-advisories/security/advisories/new)
in [Euro-Office/security-advisories](https://github.com/Euro-Office/security-advisories). You don't
need to know which repository the bug belongs to. Without a GitHub account, write to
[euro-office-team@proton.me](mailto:euro-office-team@proton.me).

What to include, what to expect and how we disclose are described in the
[security policy](https://github.com/Euro-Office/security-advisories/blob/main/SECURITY.md).
Published advisories are listed in that repository's
[Security tab](https://github.com/Euro-Office/security-advisories/security/advisories).
